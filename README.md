Blinkit Grocery Sales Analysis – Power BI Dashboard
This project analyzes Blinkit grocery store sales data using Power BI to uncover trends and performance metrics. The interactive dashboard is designed for business decision-making and provides a clear view of sales across different outlets and item categories.

Key Features:

Filter Panel: Outlet Location Type, Outlet Size, and Item Type for dynamic data exploration.

KPI Cards: Total Sales, Average Sales, Number of Items, and Average Rating for quick performance checks.

Visuals:

Matrix Table: Displays Total Sales, Average Sales, Number of Items, and Average Rating by category.

Line Chart: Outlet establishment trend over time.

Donut Chart: Sales distribution by Outlet Size.

Funnel Chart: Sales contribution by Outlet Location Type.

This dashboard provides actionable insights for sales strategy, inventory planning, and outlet performance evaluation.

Tools Used: Power BI (Data Cleaning, Data Modeling, Visualizations).
